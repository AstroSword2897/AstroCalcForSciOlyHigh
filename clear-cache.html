🔧 AstroCalc Cache Clearer

This tool will help clear all caches and service workers for AstroCalc.

Click the buttons below to clear caches.

Manual Steps (if buttons don't work):

  1. Safari: Develop → Service Workers → Unregister
  2. Chrome: DevTools (Cmd+Option+I) → Application → Service Workers → Unregister
  3. Firefox: DevTools (Cmd+Option+I) → Storage → Service Workers → Unregister
  4. Hard refresh: Cmd + Shift + R
