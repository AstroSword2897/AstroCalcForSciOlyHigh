Keyboard & symbols
  • Enter runs parse/solve when the equation box is focused.
  • Tab / Shift+Tab move between fields; inside variable inputs, Tab cycles fields then jumps to Calculate.
  • Click a Greek or math button to insert at the cursor (equation box or known-value fields).
  • Use * for multiplication or write implicit multiplication (e.g. 3x) after Parse.
  • Known values with units: type the number and unit (e.g. 23 F or 400 nm); values convert to base units for the solve.
